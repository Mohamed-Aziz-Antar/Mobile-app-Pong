# Pong Mobile Game 🎮

This project is a mobile application developed with **Flutter** and **Dart**, inspired by the classic **Pong** game, but enhanced with multiple game modes and modern features.  
The paddle is controlled through the phone’s **accelerometer**, making the gameplay more immersive and intuitive.

## 🎯 Game Modes
- **Classic**: traditional Pong, played until a chosen score limit.  
- **Time Attack**: score as many points as possible within a limited time.  
- **Multiplayer**: play against a friend over local Wi-Fi.  
- **Practice**: training mode to improve your reflexes.  

## ⚙️ Features
- **Volume**, **music**, and **vibration** settings.  
- **User profile** creation and editing.  
- **Leaderboard** ranking all players based on their scores.  
- **Authentication**: login and sign up functionality.
